# Нежить — раса для D&D

Полная homebrew-раса разумной нежити для D&D 2024: общие правила, развитие расовых способностей, десять разновидностей и готовый ревенант Маркус.

## Готовый сайт

- [GitHub Pages](https://roman161rusrosrov-cmyk.github.io/-/)
- [Основная версия](https://undead-race.chenneocosiuage10joz.chatgpt.site)

## Что внутри

- Ревенант, Скелет, Зомби, Упырь, Умертвие
- Вампирское отродье, Призрак, Мумия, Личерождённый, Могильный рыцарь
- Поиск и фильтры по стилю игры
- Полные способности каждой разновидности
- Таблица развития с 1-го по 20-й уровень
- Готовые характеристики Маркуса-ревенанта
